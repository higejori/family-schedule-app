=====================================
  家族スケジュール管理アプリの開き方
=====================================

🎯 **すぐに使いたい方（推奨）**
   standalone-app.html
   ↑このファイルをダブルクリックしてブラウザで開く
   
   ✅ Node.js不要
   ✅ インストール不要  
   ✅ すぐに使える
   ✅ オフライン動作

=====================================

🔧 **フル機能版を使いたい方**

【方法1: 自動起動】
   start.bat をダブルクリック
   
【方法2: クイックスタート】  
   quick-start.bat をダブルクリック → 「1」を選択

【方法3: 手動実行】
   1. コマンドプロンプトを開く
   2. 以下をコピー&ペースト:
   
   cd /d "C:\Claude code\06_家族スケジュール管理アプリ\family-schedule-app"
   npm install
   npm run dev
   
   3. ブラウザで http://localhost:5173/ にアクセス

=====================================

🌐 **アクセス方法**

以下のURLでアクセス可能です:

✅ http://localhost:5173/
✅ http://10.255.255.254:5173/  
✅ http://172.29.243.174:5173/

※ サーバーが起動していない場合は接続できません

=====================================

❓ **トラブル解決**

【何も開かない場合】
→ standalone-app.html を使用

【「このサイトは開けません」エラー】
→ サーバーが起動していません
→ start.bat を実行してください

【Node.jsエラー】
→ https://nodejs.org/ からインストール

【詳細診断】
→ troubleshoot.bat を実行

=====================================

📱 **使い方**

1. 休暇期間を選択
   - ゴールデンウィーク
   - お盆休み  
   - 年末年始
   - シルバーウィーク
   - カスタム期間

2. カレンダーのセルをクリック
   （行=家族メンバー、列=日付）

3. 予定を入力
   - 必要な箇所のみ入力OK
   - 空白で削除可能

4. 泊まる場所を選択
   - 1: 雄家 2: 紗家 3: 姫路 4: 旅行
   - 数字で簡単選択

5. 色分けで視覚的に確認
   - 表外の凡例で色を確認
   - 場所名は表内に表示されない

6. 「JPEG画像でダウンロード」で保存

=====================================

🎨 **色分け**

🔵 雄家 - 水色
🩷 紗家 - ピンク  
💚 姫路 - 緑
🧡 旅行 - オレンジ

=====================================

💾 **データ保存**

【スタンドアロン版】
- ブラウザのローカルストレージに自動保存
- 同じブラウザで開けば前回のデータが残る

【フル機能版】  
- 複数のスケジュールパターンを保存可能
- 名前を付けて管理
- データのインポート/エクスポート

=====================================

📞 **サポート**

問題が解決しない場合:
1. standalone-app.html を使用（最も確実）
2. troubleshoot.bat で診断実行
3. test-server.html で接続テスト

=====================================

🚀 **推奨の使用手順**

初回:
1. standalone-app.html をブラウザで開く
2. 基本的な使い方を確認
3. 問題なければフル機能版にチャレンジ

継続使用:
1. start.bat をデスクトップにショートカット作成
2. ダブルクリックで即座に起動
3. ブックマークに http://localhost:5173/ を登録
