=====================================
  家族スケジュール管理アプリ
=====================================

📅 プロジェクト名: Family Schedule Manager
🎯 目的: 家族4人の長期休暇スケジュール管理
👥 対象: 雄一郎・紗理・小夏・蒼汰さん
📱 対応デバイス: PC・タブレット・スマートフォン

=====================================
  主要機能
=====================================

✅ 長期休暇期間選択
   - ゴールデンウィーク
   - お盆休み  
   - 年末年始
   - シルバーウィーク
   - カスタム期間設定

✅ カレンダー表示
   - 日付 × 家族メンバー の表形式
   - クリックで予定入力
   - 視覚的な色分け表示

✅ 泊まる場所管理
   - 雄家（水色 #87CEEB）
   - 紗家（ピンク #FFB6C1）
   - 姫路（緑 #90EE90）
   - 旅行（オレンジ #FFA500）

✅ 予定入力システム
   - 定番活動から選択
   - 自由テキスト入力
   - プレビュー機能付き

✅ データ管理
   - ローカル保存・読み込み
   - 複数スケジューの保存
   - データ削除・クリア

✅ 画像エクスポート
   - JPEGファイルでダウンロード
   - 高解像度対応
   - 印刷・共有用

=====================================
  技術仕様
=====================================

🛠️ フレームワーク: React 18 + TypeScript
⚡ ビルドツール: Vite
🎨 スタイリング: CSS3 (Flexbox, Grid)
📅 日付処理: date-fns
🖼️ 画像生成: html2canvas
🔧 アイコン: Lucide React
💾 データ保存: LocalStorage

=====================================
  起動方法
=====================================

🚀 簡単起動:
   start.bat をダブルクリック

🔧 開発モード:
   develop.bat をダブルクリック

⌨️ コマンドライン:
   npm install
   npm run dev

🌐 アクセス: http://localhost:5173/
